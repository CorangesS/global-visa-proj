# 新西兰：中国 Working Holiday Visa

## 你的初筛：资格方向匹配；2026名额已满

- 中国公民，18–30岁，通常居住在中国且申请时实际住在中国。
- 紧接申请前在中国境外累计生活不得超过2年。
- 从未获发新西兰WHV，即使获发后没使用也不能再申请。
- 至少完成3年全日制高中；需由教育部学生服务与素质发展中心（CSSD）验证，并提交学历、验证报告和英文翻译。
- 英语必须用2年内线下考试证明；当前中国WHV门槛为：IELTS总分5.5、TOEFL iBT 46、PTE Academic 42、B2 First 162，或OET四项C及以上。
- 至少NZD4,200生活费，另有离境票或购票资金；全程医疗保险；健康和品格合格。

## 2026状态

- 每年1,000名。
- 2026-07-02开放，名额已满，页面显示Closed；官方说明满额后关闭至2027。
- 当前页面费用从NZD770起；费用会调整，提交前重查。

## 获签后

- 最长12个月；无需job offer；可临时工作，但不能做永久工作。
- 同一雇主最多6个月；学习／培训合计最多6个月；可多次出入境。
- 获签后12个月内必须入境；不能延期激活或取消重来。
- 满足农业／园艺等指定工作3个月时，可能申请额外3个月延长。

## 抢名额准备

- [ ] 提前创建并测试RealMe／移民局在线账户。
- [ ] 护照至少覆盖预计签证期后3个月。
- [ ] CSSD高中学历验证＋高中学历英文翻译。
- [ ] 2年有效期内的英语成绩，优先把目标定在IELTS 5.5以上。
- [ ] NZD4,200＋返程资金的清晰银行证明。
- [ ] INZ 1027中国公民补充表所需资料。
- [ ] 体检胸片：官方对从中国申请且来新超过6个月者有特定要求，按申请时指引办理，结果通常需3个月内。
