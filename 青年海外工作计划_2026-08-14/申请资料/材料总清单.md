# 通用材料总清单

## 现在就整理

- [ ] 护照个人信息页彩色扫描；有效期至少覆盖预计停留及官方要求。
- [ ] 身份证、户口簿、出生信息文件。
- [ ] 学位证、毕业证、完整成绩单；中文原件＋合规英文译件。
- [ ] 学信网／CSSD学历学位验证；香港项目另按入境处认可方式准备第三方或院校验证。
- [ ] 毕业后每段工作的合同、在职／离职证明、社保／个税、工资流水。
- [ ] 无犯罪记录及翻译（不要过早办理，许多项目有3或6个月有效期）。
- [ ] 近照，按各国尺寸和背景要求另存。
- [ ] 银行流水、存款证明、信用卡额度；记录资金来源，避免临时大额不明入账。
- [ ] 英语及其他语言成绩；记录考试日期和项目接受期限。
- [ ] 中英文简历；针对儿童照护另做au pair简历／家庭信。
- [ ] 驾照、无事故／驾龄证明与翻译（如适用）。
- [ ] 体检、胸片、保险只在官方要求的时间窗办理。

## 文件命名建议

`国家_项目_材料_姓名_签发日_到期日.pdf`

示例：`NZ_WHV_IELTS_ZHANGSAN_2026-10-01_2028-10-01.pdf`

## 递交前检查

- [ ] 所有姓名、出生日期、护照号与护照完全一致。
- [ ] 所有非中／英文文件满足官方翻译与认证要求。
- [ ] 资金数额除最低生活费外，还覆盖返程票要求。
- [ ] 只通过政府网、政府列名担保方／机构或真实雇主渠道递交。
- [ ] 保存表格PDF、上传文件、缴费凭证、确认邮件和提交时间截图。
