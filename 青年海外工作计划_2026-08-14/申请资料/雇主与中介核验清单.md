# 雇主、担保方与中介核验清单

任何一项答不上来，都先暂停付款。

- [ ] 雇主法定名称、注册号、办公地址、官网域名、公司邮箱可互相印证。
- [ ] 招聘人可从公司总机或官网邮箱反向验证，不只使用微信／WhatsApp。
- [ ] 项目要求担保方时，担保方确实出现在政府官方名单。
- [ ] 合同写明岗位、地点、日期、工时、时薪／月薪、扣费、住宿、交通、保险、解约规则。
- [ ] 工资不低于项目最低工资或集体协议；“到岗后再签合同”不可接受。
- [ ] 对方不会要求你用旅游签、落地后“转工签”或隐瞒实际工作。
- [ ] 所谓签证费可在政府网站查到；付款收款方与说明一致。
- [ ] 不购买“保证中签”“保录取”“内部名额”“雇主担保名额”。
- [ ] 不把护照原件长期交给雇主／中介，不共享网银、验证码、ImmiAccount等账户密码。
- [ ] 住宿扣费、押金、交通费、项目费均有书面上限和退款规则。
- [ ] 保存广告、聊天、合同、付款和投诉渠道。

项目核验入口：

- 英国持牌担保人登记册：https://www.gov.uk/government/publications/register-of-licensed-sponsors-workers
- 美国J-1指定担保人查询：https://j1visa.state.gov/participants/how-to-apply/sponsor-search/
- 荷兰IND认可担保人／au pair机构：https://ind.nl/en/public-register-recognised-sponsors
- 瑞士第三国au pair必须经获授权安置机构：https://www.sem.admin.ch/sem/en/home/themen/arbeit/faq.0006.html
